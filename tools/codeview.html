Edits stay a draft in this browser (orange dot in the tree) until you Save. A Try copy is kept the same way until you Discard it, and Save never writes it; there is one at a time, so starting Try on another file deletes the older copy. Practice attempts, their timer and the hints you opened are kept the same way, never in the file: the Attempts tab lists them and clears several at once. Clearing this browser's site data loses them. Done / Revise marks, solve times and reviews are saved on this PC in tools\codeview-state.json.

Showing the solution, or Compare, before an attempt is solved marks the file ↻ revise (the bar that says so has Undo). A pass after that does not count as solved until you Reset and solve it fresh.

Java autocomplete, parameter hints, Javadoc on hover and red underlines for javac's errors work while you edit (Edit, Try, Scratch pad). In practice mode they are off, as in most interview editors; ⋯ → Autocomplete in Practice turns them on. They come from your JDK's own compiler, running in the background; the first suggestion after a start takes a few seconds.

A file marked done comes back for review (◷ in the list) after 3 days, then 7, 21 and 60 days each time you solve it again in practice mode.
