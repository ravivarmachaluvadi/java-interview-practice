# Maths Symbols

A quick reference of the mathematical, logical and computer-science symbols the owner uses in notes, with the meaning and an example of each, grouped by category.


## 1. Set Theory & Collections

| Symbol | Meaning | Example / Usage |
| --- | --- | --- |
| ∈ | Element of | x ∈ S → x is in set S |
| ∋ | Such that | ∃x ∋ x > 0 means “there exists x such that x > 0” |
| ∉ | Not an element of | x ∉ S |
| ⊂ | Proper subset of | A ⊂ B → A is contained in B |
| ⊆ | Subset or equal | A ⊆ B |
| ⊄ | Not a subset of | A ⊄ B |
| ∪ | Union | A ∪ B → combine both sets |
| ∩ | Intersection | A ∩ B → common elements |
| ∅ | Empty set | S = ∅ → set is empty |
| ∖ | Set difference | A ∖ B → elements in A not in B |
| ℕ, ℤ, ℝ, ℂ | Number sets | natural, integer, real, complex |

## 2. Logic & Conditions

| Symbol | Meaning | Example / Usage |
| --- | --- | --- |
| ∧ | Logical AND | p ∧ q → both true |
| ∨ | Logical OR | p ∨ q |
| ¬ | NOT | ¬p → not p |
| ⇒ | Implies | p ⇒ q → if p then q |
| ⇔ | If and only if | p ⇔ q |
| ∀ | For all | ∀x ∈ S, f(x) > 0 |
| ∃ | There exists | ∃x ∈ S, f(x) = 0 |
| ⊤ / ⊥ | True / False | logic constants |

## 3. Algorithms, Math, & Analysis

| Symbol | Meaning | Example |
| --- | --- | --- |
| ≈ | Approximately equal | π ≈ 3.14 |
| ≠ | Not equal | a ≠ b |
| ≤ / ≥ | Less/greater or equal | a ≤ b |
| → | Mapping / transition | f: X → Y or state → nextState |
| ∑ | Summation | ∑ i=1..n i |
| ∏ | Product | ∏ i=1..n a[i] |
| √ | Square root | √x |
| ∞ | Infinity | while(true) → conceptual ∞ |
| ∇ | Delta / change / gradient | ∇loss in ML context |

| Symbol | Meaning | Example / Context |
