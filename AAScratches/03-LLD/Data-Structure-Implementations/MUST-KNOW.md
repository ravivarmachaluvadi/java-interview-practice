## Full practice order


### A — Building blocks

- `A01_DynamicArrayDeque.java` — Circular buffer with amortized doubling **[must-know]**
  - The most primitive item here: it teaches raw array mechanics — capacity vs size, wraparound indexing with (i + len) % len, and growth by doubling — which is the substrate every other array-backed structure in this folder (including the hash map's bucket array) sits on.
- `A02_HashMapImplementation.java` — Separate chaining hash table **[must-know]**
  - Comes second because it layers hashing and collision resolution on top of the array-of-slots idea from the deque, and its natural follow-up (resize and rehash at a load factor) is exactly the doubling argument learned in rank 1; it is also the primitive that unlocks LRU/LFU, frequency maps and every Java hashCode/equals discussion.
