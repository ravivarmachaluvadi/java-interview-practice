Ctrl+Alt+E → type your line → Ctrl+S → Ctrl+Alt+R

The line looks like this:

:?OT:;dob::15/08/1988

┌────────────┬───────────────────────────────┐
│    Part    │            Meaning            │
├────────────┼───────────────────────────────┤
│ :?OT:      │ always the same, just copy it │
├────────────┼───────────────────────────────┤
│ ;dob       │ what you type                 │
├────────────┼───────────────────────────────┤
│ ::         │ separator                     │
├────────────┼───────────────────────────────┤
│ 15/08/1988 │ what appears                  │
└────────────┴───────────────────────────────┘


┌────────────┬────────────────────────────────────┐
│    Key     │                Does                │
├────────────┼────────────────────────────────────┤
│ Ctrl+Alt+A │ manage — add, edit, delete, search │
├────────────┼────────────────────────────────────┤
│ Ctrl+Alt+G │ visual page in browser             │
├────────────┼────────────────────────────────────┤
│ Ctrl+Alt+E │ raw data file (if you prefer)      │
├────────────┼────────────────────────────────────┤
│ Ctrl+Alt+R │ reload                             │
└────────────┴────────────────────────────────────┘

Then type ;dob + Space.
