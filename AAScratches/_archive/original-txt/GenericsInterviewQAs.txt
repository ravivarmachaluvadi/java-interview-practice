Q. Can you overload methods based only on generic type parameters?
    No.
    Because generics are erased at runtime.
    Example:
    void process(List<String> list) { }
    void process(List<Integer> list) { } // compile-time error
    Erased signatures become:
    void process(List list)

        List<Number> m() { return null; }
    }
    class B extends A {
    // not because of ArrayList but Integer ArrayList is covariant return type
        @Override
        ArrayList<Integer> m() { return null; }  // 'm()' in 'B' clashes with 'm()' in 'A'; incompatible return type
    }

Q. ✅ The 3 Generic Bounded Types in Java
✅ The 3 Generic Bounded Types in Java
1. Upper Bounded Type (extends)
    Uses the keyword extends (even for interfaces).
    Syntax:
    <T extends Number>
    <? extends Number>
    Meaning:
    T can be Number or any subclass (Integer, Double, etc.)
    Used when the type is a producer (PECS rule).
    Example:
    List<? extends Number> nums; // Can read as Number
2. Lower Bounded Type (super)
    Uses the keyword super
    Syntax:
    <? super Integer>
    Meaning:
    T can be Integer or any superclass of Integer (Number, Object)
    Used when the type is a consumer
    Example:
    List<? super Integer> ints; // Can insert Integer
3. Unbounded Type (?)
    Syntax:
    List<?>
    Meaning:
    The type is unknown
    Accepts any type
    You cannot add anything except null.
    Example:
    void print(List<?> list) {
        for (Object o : list) System.out.println(o);
    }

| Bound Type      | Syntax          | Meaning            | Can Add?        | Can Read?    |
| --------------- | --------------- | ------------------ | --------------- | ------------ |
| **Upper Bound** | `<? extends T>` | Any subtype of T   | ❌               | ✔️ as T      |
| **Lower Bound** | `<? super T>`   | Any supertype of T | ✔️ T or subtype | ✔️ as Object |
| **Unbounded**   | `<?>`           | Unknown type       | ❌               | ✔️ as Object |

import java.util.ArrayList;
import java.util.List;

class Scratch {
    public static void main(String[] args) {

        List<String> list2 = new ArrayList<>();
        list2.add("Ravi");
        list2.add("Varma");
        readList(list2);
    }

    private static void readList(List<?> list2) {
        list2.forEach(System.out::println);
    }
}
